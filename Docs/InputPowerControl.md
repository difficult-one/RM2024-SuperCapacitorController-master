# F407 动态缓冲输入功率闭环

2026-10-12。匹配 NSEonLu 的 `CHASSIS_POWER_SOURCE_MODE=1` 电容模式。

F407按裁判缓冲决定输入功率目标，本板使用已有输入功率PID执行；底盘负载闭环仍由F407负责。本板不会把电容放电贡献记作输入功率，也不会在扩展生效时继续使用固定50 J能量PID。

## 指令 0x061，8字节

| 字节 | 内容 |
| --- | --- |
| 0 | bit0 DCDC使能，bit1重启，其余0 |
| 1～2 | 裁判原始功率上限，uint16小端 |
| 3～4 | 裁判原始缓冲能量，uint16小端 |
| 5～6 | 独立输入功率目标，uint16小端 |
| 7 | `0xA5`启用扩展输入闭环；0为旧指令 |

示例：原始80 W、60 J缓冲、取电目标110 W：`01 50 00 3C 00 6E 00 A5`。目标不会覆盖原始限额。板端再次根据真实缓冲限制目标，保留电流、电压和硬件故障保护。

## 反馈 0x052，8字节

字节0～3为实测电管输入功率float，4～5为输入环目标uint16，6为版本1，7的bit0表示扩展控制已生效。全部小端，保留位0。已有0x051布局保持不变，两类反馈均每5 ms发送。

F407须同时检查两类反馈的新鲜度，收到有效扩展反馈后才启用电容模式缓冲增量。旧F407不带扩展标识时使用旧能量策略。

## 使能与失联

有效指令超过100 ms未更新就关闭DCDC。冷启动没有有效启用指令时保持关闭；周期启用帧不能覆盖硬件故障锁停。显式禁用后再使能可请求重试，失联重连仅在硬件正常时自动恢复。控制状态更新采用短临界区并恢复原PRIMASK，避免更高优先级故障中断的锁停被覆盖。

整体检查后增加初始化完成门控：ADC与定时器初始化及正常硬件自检完成前，CAN启用请求不能开启输出。`CALIBRATION_MODE`用于写板号和采样，保持输出关闭，不提供正常CAN驱动功能。

扩展指令切回旧协议时立即回到不高于裁判原始限额的目标，并重置相关PID；不让旧80 ms节拍继续执行原扩展目标。

电容电流约束按功率守恒计算，不使用实测电流相除。充电A侧功率不高于`V_cap × I_charge_max`；低于5 V时电容侧限4 A，因此4.5 V对应18 W。放电能力按低压降额电流、测得效率和20%余量计算；执行限幅与状态总能力使用同一规则。测量及转换响应存在延迟，实际瞬态电流仍需台架验证。

## 验证

`make -C tests/input_power_policy test`验证帧、功率限制、5 ms节拍、100 ms边界、故障锁停与重连策略。已通过ARM完整构建，构建验证采用HARDWARE_ID=201；实际板号仍按本板配置，未烧录或改写Option Bytes。
